MODULAR COMPONENT RUNTIME

Adaptive Navigation Drawer

This module replicates the exact structure, animations, and routing conditions of the React Native CustomDrawerContent. It auto-binds user authentication state from localStorage.getItem('userData'), adapting the primary dashboard link and icon dynamically between Customer Dashboard and Agent Dashboard.

Dynamic Role Delegation

When role === 'agent', the primary navigation item renders "Agent Dashboard" with the representative briefcase/tie icon directing to agent-dashboard.html. Regular subscribers see "Dashboard" pointing to customer-dashboard.html.

Fluid Responsive States

Functions as an off-canvas slide-out drawer on smartphone & tablet touchscreens, with full backdrop dismiss and touch targets. On wider desktops, it cleanly pins alongside workspace panels.
